# simple-interest-calculator

A simple project that calculates simple interest based on principal amount, 
rate of interest, and time period. This project is part of the Git/GitHub 
final assignment.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest (per year)
- T = Time period (in years)

## Features
- Takes principal, rate, and time as input
- Calculates simple interest
- Displays the total amount (principal + interest)
